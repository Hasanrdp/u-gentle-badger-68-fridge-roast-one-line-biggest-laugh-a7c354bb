# Fridge Roast: One Line, Biggest Laugh

A one-line roast of a smart fridge, written for the
[make.fun bounty](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb).

## The line

> My fridge beeps when the door's open four seconds, then pushes a notification saying 'You did this' — I'm being scolded by an appliance that can't even make ice.

161 characters. No firmware-update joke, no ice-maker strike, no camera
watching you eat at 2 a.m. — the field is full of those. This one roasts the
fridge from a fresh angle: a door alarm that acts like a disappointed parent,
backed by a push notification, from an appliance that cannot even do its one
job.

## How it works

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`. The expected output is pinned inside the program by an
exact character count, byte count and sha256 hash, and the program refuses to
write anything that does not match all three.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
